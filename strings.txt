	EN	Use your own Last.fm API key
	FR	Utiliser votre propre clé API Last.fm

PLUGIN_LASTMIX_USE_CUSTOM_API_KEY_DESC
	DE	Standardmässig teilen sich alle LastMix-Benutzer denselben API-Schlüssel. Bei hoher Auslastung kann Last.fm dessen Anfragen begrenzen ("Rate Limit Exceeded"), und LastMix liefert dann keine Titel mehr. Mit einem eigenen, kostenlosen API-Schlüssel bist du davon nicht betroffen. Ist diese Option deaktiviert, wird der mit dem Plugin gelieferte Schlüssel verwendet.
	EN	By default all LastMix users share the same API key. When it's under heavy use Last.fm may throttle its requests ("Rate Limit Exceeded"), and LastMix stops returning tracks. Using your own free API key avoids this. If this option is disabled, the key shipped with the plugin is used.
	FR	Par défaut, tous les utilisateurs de LastMix partagent la même clé API. En cas de forte sollicitation, Last.fm peut en limiter les requêtes ("Rate Limit Exceeded") et LastMix ne renvoie alors plus de morceaux. Utiliser votre propre clé API, gratuite, évite ce problème. Si cette option est désactivée, la clé fournie avec le plugin est utilisée.
	NL	Standaard delen alle LastMix-gebruikers dezelfde API-sleutel. Bij intensief gebruik kan Last.fm de aanvragen ervan beperken ("Rate Limit Exceeded"), waardoor LastMix geen nummers meer teruggeeft. Met je eigen, gratis API-sleutel heb je hier geen last van. Als deze optie is uitgeschakeld, wordt de met de plugin meegeleverde sleutel gebruikt.
